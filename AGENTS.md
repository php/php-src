# Agents

## Pull requests

Before starting work and again before opening a pull request, check for existing
pull requests as described in [CONTRIBUTING.md](CONTRIBUTING.md#pull-requests).
Do not open a duplicate of an existing pull request, unless you have a very good
reason to do it.

## Vulnerability reports

When scanning php-src for vulnerabilities, please respect our security policy
described in [SECURITY.md](SECURITY.md).
